"# esta-app" 
Бұл React Native, Expo және TypeScript көмегімен Figma дизайн-макеті бойынша жасалған оқу мобильді қосымшасы.

Пайдаланушы аккаунтқа кіре алады немесе тіркеле алады, телефон нөмірін растау арқылы құпия сөзді қалпына келтіре алады, өз қаласын таңдап, мекемелер тізіміне өте алады. Каталогта атауы бойынша іздеу бар. Мекеме бетінде рейтингі, мекенжайы және жұмыс уақыты көрсетіледі, оны таңдаулыларға қосуға және үстел брондауға болады. Профильде қаланы және құпия сөзді өзгертуге немесе аккаунттан шығуға болады.

Әр экран жеке файлда сақталған. Ортақ элементтер (батырмалар, енгізу өрістері, экран қаңқасы) components папкасында тұр, ал экрандар арасындағы ауысулар React Navigation арқылы бапталған.
